# 🎮 GameZone Retro

**Atividade Aula 5 - HTML Parte 1**.

## 📋 Sobre o projeto

O projeto consiste na criação de uma página promocional para uma loja fictícia de jogos clássicos chamada **GameZone Retro**.

A página foi desenvolvida utilizando apenas **HTML**, com foco nos principais elementos apresentados em aula.

## 🎯 Objetivo

Criar uma página simples e funcional de uma loja de games retro, utilizando uma estrutura HTML organizada e com no máximo **50 linhas de código**.

## ✅ Requisitos utilizados

* Estrutura básica de um documento HTML
* Título e parágrafos
* Textos em **negrito** e *itálico*
* Lista de consoles retro
* Link interno para a tabela de preços
* Link externo para o YouTube
* Imagem relacionada ao tema
* Tabela com jogos, consoles e preços
* Código com menos de 50 linhas

## 🎮 Conteúdo da página

A página apresenta alguns consoles clássicos, como:

* Nintendo (NES)
* Super Nintendo (SNES)
* Sega Genesis
* Atari 2600

Também possui uma tabela com jogos e seus respectivos preços, incluindo **Super Mario Bros, Sonic e Zelda**.

## 🔗 Navegação

A página possui um link interno que leva diretamente para a tabela de preços e um link externo para um canal do YouTube.

## 🖼️ Imagem

Foi utilizada uma imagem chamada `retrogames.jpg`, apresentada como banner relacionado ao tema de jogos retro.

## ▶️ Como executar

1. Baixe ou clone este projeto.
2. Mantenha o arquivo `retrogames.jpg` na mesma pasta do arquivo HTML.
3. Abra o arquivo `gamezone.html` em qualquer navegador.
4. Teste os links e a navegação até a tabela de preços.
